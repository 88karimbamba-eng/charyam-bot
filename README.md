# charyam-bot
Telegram bot with Claude AI

## Intégrations (facultatives)

Recherche web (Perplexity), lecture de pages (Firecrawl), navigateur (Playwright) et applications en lecture seule (Composio). Chaque outil n'est actif que si sa configuration est complète ; sans clé, le bot fonctionne comme avant.

- Installation, clés, sécurité, tests et retour arrière : [docs/INTEGRATIONS.md](docs/INTEGRATIONS.md)
- Variables d'environnement (valeurs fictives) : [.env.example](.env.example)
- État des outils depuis Telegram : `/outils`
